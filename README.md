# AZ DIGITAL LAB

A responsive bilingual (English/Arabic) landing page for AZ DIGITAL LAB.

## Preview locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then save.
4. GitHub will publish the site and show its URL in the Pages section.

## Before launch
Replace the TikTok button URL in `index.html` with your actual profile URL and add verified contact details. Do not publish private phone numbers or credentials.
